# Luis Fernandes — Developer Portfolio

A responsive, accessible portfolio website built with plain HTML, CSS and JavaScript for the Coursera web development assignment. No build tools or dependencies required.

## Before you publish

1. Open `index.html` and replace `https://github.com/` with your full GitHub profile URL.
2. Replace `https://www.linkedin.com/` with your LinkedIn profile URL.
3. Find `YOUR_EMAIL@example.com` and replace it with your actual email address.
4. Remove the placeholder notice under Contact after making these changes.
5. Review the biography, skills and project descriptions for accuracy; add links to your own project repositories if desired.

## Preview locally

Open `index.html` in a web browser. All files should remain in the same folder.

## Publish using GitHub Pages

1. Create a public GitHub repository, e.g. `developer-portfolio`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root, and commit them.
3. In the repository, go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.
5. The website should be served at `https://YOUR-USERNAME.github.io/developer-portfolio/` (replace YOUR-USERNAME and the repository name). It can take a little while for deployment to become active.
6. Submit that live URL to Coursera.

## Features for the grading rubric

- **HTML**: semantic header, navigation, main, sections, articles and footer.
- **Accessibility**: descriptive image alternatives (aria-label for CSS illustrations), skip link, screen-reader status announcements, keyboard-focus styles, accessible navigation controls.
- **CSS**: consistent styling, cards, typography and dark/light themes.
- **JavaScript**: mobile navigation toggle, persistent theme toggle, project filtering and copy-email interaction.
- **Responsive**: CSS media queries for tablet and mobile screen sizes.

No contact form sends messages. Contact placeholders intentionally avoid inventing personal contact details.
