My Developer Portfolio
Hi, I'm Luis. This is my personal portfolio website, built as part of my web development coursework. I also wanted to make something I could keep improving and eventually use when applying for software development roles.
I work with IT and reporting in the financial sector, and I've been expanding my skills in software development. This site is a place to introduce myself, share what I'm learning, and show some of the projects I've worked on.
What I used
I kept the website simple: HTML for the content, CSS for the layout and styling, and JavaScript for the interactive parts. It includes a light/dark theme switch, a mobile menu and project filters. The layout also adapts to smaller screens.
